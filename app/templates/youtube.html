Firefox (le plus simple) :
  1. Ouvre music.youtube.com connecté au bon compte (ou à la bonne chaîne de marque).
  2. F12 → onglet Réseau → filtre browse.
  3. Clique sur Bibliothèque : une requête POST browse?… apparaît.
  4. Clic droit dessus → Copier la valeur → Copier les en-têtes de la requête, puis colle ci-dessous.
Chrome / Edge : clique sur la requête → onglet En-têtes → « En-têtes de requête » → coche Brut (ou View source) → copie tout.
La session reste valide tant que tu ne te déconnectes pas de YouTube dans ce navigateur (évite la navigation privée).
